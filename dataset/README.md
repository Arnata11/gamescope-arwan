# Dataset

Unduh file CSV dari sumber Kaggle resmi:
https://www.kaggle.com/datasets/gregorut/videogamesales

Simpan sebagai `vgsales.csv` di folder ini. Dataset tidak disertakan dalam paket proyek. Setelah menambahkan CSV, jalankan:

```bash
python scripts/clean_data.py
```

Skrip akan membuat `vgsales_clean.csv`. Periksa ketentuan sumber dataset sebelum memublikasikan salinan CSV di repository publik.
